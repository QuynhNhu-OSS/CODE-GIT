Ứng dụng này dùng NNLT PHP để chạy. 
Để chạy được ứng dụng bạn cần có Server ảo trên máy (Xampp hoặc WampServer). 
Tải tệp index.php và 2 tệp dữ liệu thực nghiệm, lưu trong 1 thư mục (giả sử đặt tên là web), nằm trong thư mục htdocs của xampp (C:/xampp/htdocs).
Khởi chạy xampp (Apache và MySQL), truy cập trình duyệt và nhập đường dẫn: localhost/web/index.php, ứng dụng sẽ được khởi chạy.
/////////
This application uses PHP to run.
To run the application, you need a virtual server on your computer (Xampp or WampServer).
Download the index.php file and 2 experimental data files, save them in a folder (let's say named web), located in the htdocs folder of xampp (C:/xampp/htdocs).
Launch xampp (Apache and MySQL), access the browser and enter the path: localhost/web/index.php, the application will be launched.
